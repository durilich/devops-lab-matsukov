# devops-lab-matsukov

Репозиторий для лабораторных работ по курсу DevOps (Lab 0: создание репозитория и настройка рабочего окружения).

## Описание

Проект создан для практики базовых DevOps-навыков: работа с Git и GitHub, настройка SSH, ветвление, Pull Request и оформление репозитория.

## План изучения DevOps

1. **Основы Git и GitHub** — репозитории, ветки, коммиты, PR, merge
2. **Linux и командная строка** — навигация, права, процессы, скрипты
3. **Контейнеризация** — Docker, образы, контейнеры, Docker Compose
4. **CI/CD** — GitHub Actions / GitLab CI, автоматическая сборка и деплой
5. **Инфраструктура как код** — основы Terraform / Ansible
6. **Мониторинг и логирование** — базовые практики observability
7. **Облака** — знакомство с облачными сервисами и деплоем приложений

# Contributing

## Как внести изменения

1. Создайте ветку от `main` или `develop`
2. Внесите правки
3. Сделайте коммит с понятным сообщением
4. Отправьте ветку и создайте Pull Request

## Правила

- Не коммитьте секреты (пароли, токены, ключи)
- Не коммитьте служебные файлы ОС и IDE (см. `.gitignore`)
- В PR кратко опишите, что изменено
